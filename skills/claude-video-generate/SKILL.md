# /generate — генерация медиа через агрегаторы

Замена подписочным сервисам вроде Higgsfield: те же модели, но оплата только за фактические генерации. Три провайдера, маршрутизация по цене, подтверждение стоимости до траты, локальный лог всех промптов и файлов.

## Обязательный порядок

**1. Проверь ключи.** `env | grep -E 'KIE_API_KEY|FAL_KEY|WAVESPEED_API_KEY'`. Если нет ни одного — скажи, какие завести и где взять (`kie.ai/api-key`, `fal.ai/dashboard/keys`, `wavespeed.ai`), и остановись. Работать можно и с одним ключом, маршрутизация просто сузится.

**2. Пойми задачу.** Что именно: изображение с нуля, редактирование по референсу, видео из текста, видео из картинки, апскейл. Какое соотношение сторон, сколько вариантов, для чего это (сайт, соцсети, печать). Если пользователь дал референс — уточни, это образец стиля или конкретное изображение, которое надо изменить: от этого зависит модель.

**3. Выбери модель** по `references/routing.md`. Правило по умолчанию — самое дешёвое, что решает задачу: kie.ai → fal.ai → wavespeed. Отступай от него осознанно и скажи почему (нужной модели нет дешевле, у kie очередь, нужен sync-режим).

**4. Напиши промпт.** Пользователь даёт идею, ты — технический промпт: сюжет, композиция, свет, материал, оптика, палитра, настроение. Плохой промпт дороже дорогой модели. Если в `references/styles.md` есть подходящий пресет — примени и скажи какой.

**5. Назови цену и дождись «да».** Перед каждым платным вызовом одной строкой: модель, провайдер, количество, оценка в долларах. Без явного согласия не запускай. Исключение — пользователь заранее сказал «не спрашивай» в этой сессии.

**6. Проверь бюджет.** `python3 scripts/gen.py spent --since today`. Лимит по умолчанию — **$3 за сессию**. На подходе к лимиту предупреди, за лимитом остановись и спроси.

**7. Запусти.**

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/gen.py" run \
  --provider kie --model google/nano-banana \
  --input '{"prompt":"...","aspect_ratio":"1:1","output_format":"png"}' \
  --cost 0.02 --note "референс для карточки"
```

Скрипт сам опрашивает статус, скачивает файлы в `generations/ГГГГ-ММ-ДД/` и дописывает строку в `generations/log.jsonl`. Никогда не дёргай API curl-ом в обход скрипта: тогда генерация не попадёт в лог и бюджет поедет.

**8. Отдай результат.** Путь к файлу, что получилось, и что можно поменять следующим шагом. Если вышло плохо — предложи правку промпта, а не сразу другую модель: перезапуск на той же модели обычно дешевле.

## Правила расходов

- Ничего не запускается без озвученной цены.
- Лимит сессии $3, если пользователь не сказал другое. `gen.py spent` — источник правды.
- Видео дороже картинок в десятки раз. Перед видео цену называй **всегда**, даже если пользователь отключил подтверждения.
- Батч больше 4 генераций разбивай: сначала одна пробная, показать, потом остальные.
- Сравнение моделей («покажи на трёх») — это трата ×3. Скажи сумму до запуска.
- Провалившаяся задача пишется в лог с нулевой ценой. У fal серверные ошибки не тарифицируются, у остальных — проверяй баланс.

## Логирование

`generations/log.jsonl`, по строке на генерацию: время, провайдер, модель, полный input, оценка цены, ссылки и локальные пути. Это и есть владение контентом — промпты остаются у пользователя, а не в чужом веб-интерфейсе.

- `gen.py log --last 20` — что генерировали недавно
- `gen.py spent --since all` — суммарная трата
- `gen.py balance` — остаток у всех провайдеров, где ключ задан

## Референсные изображения

Ни один провайдер не принимает локальный файл прямо в теле запроса — нужна публичная ссылка. Порядок действий в `references/uploads.md`. Коротко: у kie есть свой аплоадер, у wavespeed — подписанный PUT, у fal по чистому HTTP аплоада нет, там либо своя ссылка, либо data-URI для мелких файлов.

## Расширение

Появилась новая модель — не переписывай навык целиком: добавь строку в таблицу `references/routing.md` и, если у провайдера другая форма ответа, поправь `_harvest_urls` в скрипте. Чтобы добавить провайдера, скопируй класс в `scripts/gen.py` — интерфейс из трёх методов: `submit`, `poll`, `balance`.

Цены и слаги моделей устаревают быстро. Если вызов вернул «модель не найдена» — не подбирай слаг наугад, открой доки провайдера и сверься.

## Границы

- Не генерируй изображения реальных людей по имени и не воспроизводи стиль ныне живущего художника по его имени — опиши визуальные признаки вместо имени.
- Ключи не печатай в чат и не пиши в файлы репозитория.
- Скачанные файлы кладутся в `generations/`; эту папку стоит держать в `.gitignore`.
