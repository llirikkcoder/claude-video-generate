# Референсные изображения: как передать локальный файл

Ни один из трёх провайдеров не принимает локальный путь. Нужна публичная ссылка или, местами, data-URI.

## kie.ai — свой аплоадер

Отдельный хост, не `api.kie.ai`:

```bash
curl -s -X POST https://kieai.redpandaai.co/file-upload-api/upload-file-stream \
  -H "Authorization: Bearer $KIE_API_KEY" \
  -F "file=@/path/to/ref.png"
```

Ответ: `fileId, fileName, fileUrl, downloadUrl, expiresAt, fileSize, mimeType`. Берём `fileUrl`.

Есть ещё `/upload-file-base-64` (до ~10 МБ) и `/upload-file-url` (до 100 МБ, таймаут скачивания 30 с).

Файлы удаляются через 3 дня, ссылки живут 24 часа. Для долгой работы над одним референсом лучше своё хранилище.

## wavespeed.ai — подписанный PUT в два шага

```bash
# 1. получить подпись
curl -s -X POST https://api.wavespeed.ai/api/v3/media/uploads \
  -H "Authorization: Bearer $WAVESPEED_API_KEY" -H "Content-Type: application/json" \
  -d '{"filename":"ref.png","size":204800,"content_type":"image/png"}'

# 2. залить байты по data.upload.url методом data.upload.method с data.upload.headers
#    ВАЖНО: свой API-ключ в этот PUT не отправлять

# 3. в модель передавать data.download_url
```

До 200 МиБ, хранение 7 дней.

## fal.ai — публичного HTTP-аплоада нет

Загрузка в fal CDN документирована только через их SDK (`fal_client.upload_file()` в Python, `fal.storage.upload()` в JS). Плоского curl-эндпоинта, отдающего пригодную для модели ссылку, в доках нет.

Варианты по чистому HTTP, в порядке предпочтения самой fal:

1. **Presigned-ссылка** на S3 / GCS / R2 — если есть своё хранилище.
2. **Любая публичная ссылка** — например, файл, уже лежащий на сайте.
3. **data-URI в base64** — поддерживается официально, но только для мелких файлов; на паре сотен килобайт запрос распухает и начинает отваливаться.

Практично: если файлы уже нужно куда-то класть, поставь `fal-client` через pip и заливай им, а генерацию всё равно гони через `gen.py`.

## Сколько живут выходные файлы

| Провайдер | Хранение результата |
|---|---|
| fal | минимум 7 дней, по умолчанию публично; заголовком `X-Fal-Object-Lifecycle-Preference` можно сократить срок и закрыть доступ |
| kie | 14 дней |
| wavespeed | не документировано явно; загруженные входные файлы — 7 дней |

`gen.py` скачивает результат сразу после успеха, так что на срок хранения полагаться не нужно. Но ссылки в логе через неделю-другую протухнут — ценность лога в промптах и локальных путях, не в URL.
