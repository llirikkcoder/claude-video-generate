# Generate

Claude Code плагин с командой `/generate` — генерация изображений и видео через агрегаторы моделей (kie.ai, fal.ai, wavespeed.ai) по принципу pay-as-you-go вместо подписки (замена сервисам вроде Higgsfield).

## Установка

```
claude plugin marketplace add llirikkcoder/claude-video-generate
claude plugin install claude-video-generate@claude-video-generate
```

## Настройка

Нужен хотя бы один ключ (можно и все три — тогда шире выбор моделей и дешевле маршрутизация):

| Переменная | Где взять |
|---|---|
| `KIE_API_KEY` | kie.ai/api-key |
| `FAL_KEY` | fal.ai/dashboard/keys |
| `WAVESPEED_API_KEY` | wavespeed.ai |

Плагин сам проверяет, какие ключи заданы, и подскажет, каких не хватает.

## Использование

```
/generate сделай референс для карточки товара, квадрат, в стиле абстрактной живописи
```

Перед каждым платным вызовом плагин озвучивает модель, провайдера и цену в долларах и ждёт согласия — без него ничего не запускается. По умолчанию лимит расходов **$3 за сессию**.

Полезные команды через `scripts/gen.py`:

- `python3 scripts/gen.py balance` — остаток у всех провайдеров, где задан ключ
- `python3 scripts/gen.py spent --since today` — сколько потрачено сегодня
- `python3 scripts/gen.py log --last 20` — последние генерации

## Логирование

Каждая генерация пишется в `generations/log.jsonl`: время, провайдер, модель, полный input, цена, ссылки и локальные пути к файлам. Промпты и результаты остаются у пользователя, а не в чужом веб-интерфейсе. Папку `generations/` стоит держать в `.gitignore` своего проекта.

## Границы

- Не генерирует изображения реальных людей по имени и не воспроизводит стиль ныне живущего художника по его имени.
- Ключи не печатаются в чат и не попадают в файлы репозитория.
